# MayskGallery — запуск и проверка через GitHub Desktop

## Что находится в этом архиве

Это исходный Android-проект MayskGallery из присланного архива. Сохранены существующие экраны, галерея, альбомы, редактор, настройки и GitHub Actions для сборки APK.

**Важно про коллажи:** библиотека PuzzleLayout пока НЕ подключена к рабочему экрану. В проекте пока остаётся прежний конструктор. Я не стал добавлять неподтверждённую версию зависимости: у репозитория PuzzleLayout на GitHub не опубликован готовый Release, а точный номер версии для JitPack нельзя безопасно угадать. Сначала нужно зафиксировать исходники библиотеки/проверить сборку и затем заменить именно модуль коллажей. Остальные разделы приложения не трогаем.

## Загрузка через GitHub Desktop

1. Распакуйте ZIP в обычную папку, например `C:\Projects\MayskGallery`.
2. Откройте GitHub Desktop.
3. Выберите **File → Add Local Repository…**.
4. Укажите папку `MayskGallery`.
5. Если GitHub Desktop распознал репозиторий, проверьте вкладку **Changes**. В этом архиве добавлен этот файл-инструкция.
6. В поле Summary напишите `Add project test instructions` и нажмите **Commit to main**.
7. Нажмите **Push origin**. Если GitHub попросит войти — войдите в свой аккаунт.

> В архиве сохранена Git-история исходного проекта и его настроенный `origin`. Перед Push убедитесь, что это ваш репозиторий `borz95rg/MayskGallery`. Если хотите загрузить проект в другой репозиторий, сначала измените `origin` через **Repository → Repository settings → Remote**.

## Как получить APK

1. Откройте репозиторий на GitHub.
2. Перейдите во вкладку **Actions**.
3. Откройте последний запуск workflow **Build APK**.
4. Дождитесь зелёной отметки `Success`.
5. Внизу страницы в разделе **Artifacts** скачайте `MayskGallery-...`.
6. Распакуйте скачанный ZIP-архив и установите APK на Android.

Если Actions не запустился автоматически: **Actions → Build APK → Run workflow → Run workflow**.

## Сборка на компьютере

Откройте папку проекта в Android Studio (JDK 17, Android SDK 35). Дождитесь синхронизации Gradle и выполните **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Проверка офлайн

После установки включите авиарежим и проверьте локальные функции: просмотр фотографий, альбомы, редактор и создание/сохранение коллажа. Отдельно проверьте функции обновления — они закономерно требуют интернет.
