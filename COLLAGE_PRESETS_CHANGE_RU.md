# Изменение раздела «Коллаж»

- Убран прежний каталог из 100 пунктов, который фактически повторял 20 геометрий пять раз.
- Оставлены 20 разных локальных пресетов, без сетевых запросов и загрузки шаблонов во время работы.
- Генерация и сохранение коллажа остаются на устройстве; выбранные фото не отправляются на сервер.

## Важное про PuzzleLayout

Рассмотрена бесплатная библиотека https://github.com/hypersoftdev/PuzzleLayout (Apache-2.0). В публичном README указана зависимость с заполнителем версии `x.x.x`, но подтверждённый опубликованный релиз/версия для подключения не указаны. Поэтому не добавляли неподтверждённую Gradle-зависимость, которая могла бы сломать сборку GitHub Actions. Текущая версия сокращает повторяющийся каталог, но не заявляется как завершённая интеграция стороннего PuzzleLayout.

Чтобы полноценно заменить текущий рендерер сторонней библиотекой, нужно проверить опубликованный артефакт/тег и адаптировать её View API к текущему Compose-экрану, затем выполнить реальную сборку APK.
