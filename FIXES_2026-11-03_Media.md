# MayskGallery — исправления медиатеки (03.11.2026)

## Что изменено
- Корзина перечитывается при возвращении на экран и после системного диалога Android.
- Добавлена команда «Очистить всё» с подтверждением и штатным системным запросом Android на окончательное удаление всех элементов корзины.
- Сохранены отдельные действия «Восстановить» и «Удалить навсегда» для каждого файла.
- При возврате в приложение медиатека перечитывается из MediaStore, чтобы новые фото и видео появлялись без перезапуска.
- При сортировке даты используется DATE_TAKEN, затем DATE_MODIFIED, затем DATE_ADDED — это исправляет снимки камер, у которых DATE_TAKEN не заполнен.
- Добавлено разрешение READ_MEDIA_VISUAL_USER_SELECTED для Android 14+ наряду с полным доступом к фото и видео.
- Расширено распознавание селфи по имени/папке и EXIF-полям (LensModel, ImageDescription, UserComment и др.).

## Ограничения, которые важно понимать
- Android не предоставляет универсального достоверного признака «снято фронтальной камерой» для каждого файла. Некоторые производители не записывают такой признак в EXIF и сохраняют фронтальные и основные снимки в один DCIM/Camera. Для таких файлов автоматическая классификация остаётся ограниченной; нельзя безопасно объявить все портреты селфи.
- Корзина MediaStore доступна на Android 11+. Финальное удаление и восстановление могут требовать системного подтверждения Android.
- В архиве отсутствует Gradle Wrapper (`gradlew`), а в среде проверки нет установленного Gradle. Поэтому компиляция APK не запускалась; изменения исходников требуют проверки сборкой в Android Studio/GitHub Actions.
