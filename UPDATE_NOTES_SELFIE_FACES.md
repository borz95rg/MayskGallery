# Селфи по лицам и доступ Android 14

- Раздел «Селфи»: ML Kit Face Detection (на устройстве, без интернета) ищет крупные лица (1–3 лица, не меньше ~6% кадра),
  плюс прежние признаки (имя/альбом, EXIF). Результаты кэшируются в `face_index.json`.
- Ручная отметка: кнопка «+» добавляет фото в селфи, крестик на карточке убирает. Ручное решение главнее автоопределения.
- Android 14+: доступ «только выбранные фото» теперь считается рабочим (раньше приложение показывало экран разрешений).
  Состояние доступа перепроверяется при каждом возврате в приложение.
- Вкладка «Фото» без видео, перечитывание медиатеки при возврате, корзина (восстановить/удалить/очистить) уже были в этой версии.
