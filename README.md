# 📸 Maysk Gallery AI

Не просто храните фотографии. Управляйте воспоминаниями.

Галерея для Android (Kotlin + Jetpack Compose) с настраиваемым интерфейсом, ИИ-поиском на устройстве и автообновлением через GitHub Releases.

## Что уже есть

| Раздел | Что работает |
|---|---|
| Галерея | Фото и видео по датам (Сегодня / Вчера / Эта неделя / месяц), избранное |
| Альбомы | Папки устройства, 6 видов: карточки, плитка, список, круги, стекло, минимализм |
| AI Поиск | Распознавание на устройстве (ML Kit), категории (дети, животные, машины, дом, природа, документы, еда, цветы…), поиск по-русски: «машина», «собака», «цветы» |
| Просмотр | Свайп вправо/влево, вниз — закрыть, вверх — информация, двойной тап — зум, поделиться, избранное, изменить, удалить (в корзину Android) |
| Конструктор интерфейса | 7 тем (Classic, Modern, Glass, Luxury, Neon, Minimal, iStyle), колонки 2–8, закругление, прозрачность стекла, тень, анимации, шрифт, панель сверху/снизу |
| Обновления | Проверка новой версии на GitHub при запуске и кнопкой, скачивание и установка APK |

Пока не сделано (следующие этапы): редактор с фильтрами, облако, секретный альбом, виджет, настройка жестов, встроенный видеоплеер, AI-улучшение фото.
Цветовой поиск («красная машина») ML Kit не умеет: слово «красная» игнорируется, найдутся все машины.

## 1. Первый запуск через GitHub Desktop

1. Откройте `gradle.properties` и впишите свой логин GitHub:
   ```
   github.owner=ВАШ_ЛОГИН
   github.repo=MayskGallery
   ```
2. GitHub Desktop → **File → Add local repository…** → выберите папку проекта. Если предложит создать репозиторий — согласитесь (**Create a repository**).
3. **Commit to main** → **Publish repository**.
   **Снимите галочку «Keep this code private»**: приложение читает релизы без токена, у закрытого репозитория обновления не заработают.
4. На github.com откройте репозиторий → вкладка **Actions**. Сборка стартует сама (3–6 минут).
5. Готовый APK: **Actions → последний запуск → Artifacts → MayskGallery-…**. Скачайте, распакуйте zip, установите APK на телефон.

## 2. Как выпускать новые версии (и обновлять приложение на телефоне)

1. Внесите изменения в код → **Commit** → **Push origin** в GitHub Desktop.
2. Создайте тег версии. Два способа:
   - **В GitHub Desktop:** вкладка **History** → правый клик по последнему коммиту → **Create Tag…** → `v1.0.1` → затем **Push origin** (теги отправятся вместе).
   - **На сайте:** репозиторий → **Releases → Draft a new release** → Choose a tag → введите `v1.0.1` → Create new tag → **Publish release**.
3. Actions соберут APK и прикрепят его к релизу `v1.0.1`.
4. Установленное приложение при запуске спросит GitHub, есть ли релиз новее, чем текущая версия, и покажет окно **«Доступна версия 1.0.1 → Обновить»**. Также можно нажать **Настройки → Проверить обновления**.

Версии сравниваются по числам: `v1.10.0` новее `v1.9.3`. Номер версии в APK берётся из тега, так что вручную его нигде менять не нужно.

При первом обновлении Android попросит разрешить «установку из этого источника» для Maysk Gallery — включите и нажмите «Обновить» ещё раз.

## 3. Подпись APK (важно для обновлений)

Android ставит обновление поверх приложения, только если APK подписан **тем же ключом**. По умолчанию проект подписывается ключом `app/maysk-debug.keystore` из репозитория — всё работает сразу, но ключ публичный. Для личного использования этого достаточно. Если будете раздавать приложение другим людям, создайте свой ключ:

```
keytool -genkeypair -v -keystore release.keystore -alias maysk -keyalg RSA -keysize 2048 -validity 10000
```

Затем на GitHub: **Settings → Secrets and variables → Actions → New repository secret**, добавьте четыре секрета:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое `release.keystore` в base64. Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.keystore"))` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `maysk` |
| `KEY_PASSWORD` | пароль ключа |

Файл `release.keystore` в репозиторий не кладите и сохраните в надёжном месте: потеряете — обновления поверх установленной версии станут невозможны. Если смените ключ, на телефоне придётся один раз удалить старую версию.

## 4. Сборка на своём компьютере (по желанию)

Откройте папку в Android Studio (Ladybug или новее), подождите синхронизации Gradle и нажмите ▶. Gradle Wrapper в проекте нет, Android Studio предложит скачать нужную версию Gradle сама.

## Структура

```
app/src/main/java/com/maysk/gallery/
  data/     MediaStore, настройки (DataStore), модели
  ai/       ML Kit индексатор и словарь категорий
  update/   проверка релиза на GitHub и установка APK
  ui/       экраны Compose: галерея, альбомы, поиск, просмотр, конструктор
.github/workflows/build.yml   сборка и публикация релизов
```
