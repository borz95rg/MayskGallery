# Исправления MayskGallery — 03.11.2026

## Корзина
- Причина: на Android 11+ удалённые файлы не попадают в обычный запрос MediaStore, а условие `IS_TRASHED = 1` в selection игнорируется. Теперь используется `Bundle` с `QUERY_ARG_MATCH_TRASHED = MATCH_ONLY` (корзина) / `MATCH_EXCLUDE` (галерея).

## Селфи
- Раньше учитывался только альбом `Selfies`; штатная камера кладёт фото в `Camera`.
- Теперь: альбом/имя файла (selfie, front) + EXIF `LensModel` содержит «front». Результат кэшируется (`media_meta.json`).

## Места
- Причина: не было разрешения `ACCESS_MEDIA_LOCATION`, поэтому Android вырезал GPS из EXIF. Добавлено разрешение и `MediaStore.setRequireOriginal`.
- Карточка «места» вела в альбомы — теперь ведёт на новый экран «Места»: фото группируются по месту, название города через Geocoder (кэш `place_names.json`).
- EXIF больше не читается заново при каждом открытии — используется кэш.
