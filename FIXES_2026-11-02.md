# Исправления MayskGallery — 02.11.2026

## Исправление сборки
- Удалены оставшиеся маркеры незавершённого Git merge из `ExtraFeaturesScreen.kt`.
- Восстановлена единая реализация `CollageTemplatePreview`; убран вызов несуществующей `TemplatePhotoPreview`.
- Это устраняет каскад Kotlin-ошибок в районе строк 502–575 и последующие ошибки структуры файла.

## Раздел «Селфи»
- Экран больше не запускает CameraX, не запрашивает разрешение CAMERA и не показывает интерфейс съёмки.
- Показывает только фотографии из альбома `Selfies` или с префиксом имени `SELFIE_`; видео и обычные снимки основной камеры исключены.
- Если подходящих фото нет, выводится «Селфи пока нет».
- Нажатие на фото открывает просмотр.

## «Корзина»
- Список читается из `MediaStore` по `IS_TRASHED = 1`.
- Добавлен фактический счётчик содержимого корзины.
- Восстановление выполняется через системный `createTrashRequest(..., false)`.
- Окончательное удаление — через системный `createDeleteRequest`, с подтверждением Android.
- После системного действия список перечитывается.
- На Android 10 и старше приложение больше не удаляет выбранные файлы безвозвратно под видом перемещения в корзину: показывает предупреждение, что системная корзина требует Android 11+.

## Проверка
- Проверено отсутствие оставшихся merge-конфликтов и вызовов удалённой функции предпросмотра.
- Полную Gradle-сборку в этой среде выполнить не удалось: в архиве проекта отсутствует `gradlew`, а системный Gradle не установлен. Для окончательной проверки нужно запустить GitHub Actions после загрузки исправленного архива.
