# MayskGallery — следующий этап обновления

## Принципы
- Сохраняется оригинальная главная страница с фигурным баннером, четырьмя быстрыми карточками, альбомами, воспоминаниями и нижней панелью «Фото — Альбомы — Видео».
- Цветовые темы меняют оформление, а не структуру навигации.
- Существующий сейф и его PIN-хэш не сбрасываются.
- Существующие скрытые файлы в корне сейфа продолжают читаться; новые скрытые файлы раскладываются по приватным папкам на основе исходного альбома.

## Добавлено в исходники этого этапа
- Расширены сохраняемые настройки: оформление, параметры сетки и дат, безопасность, подтверждение удаления, предпочтительный срок корзины, воспоминания, виджет, язык/дата и интервал слайд-шоу.
- Подтверждение перемещения в корзину можно включать и выключать.
- Настройки группировки и показа дат применяются в общей галерее.
- Настройка блокировки сейфа при сворачивании и переключатель биометрии связаны с существующим PIN/биометрическим входом.
- Воспоминания можно скрыть с главной страницы; экран воспоминаний даёт выбор года.
- Добавлены инструменты: поиск точных дубликатов по SHA-256 (с предварительной группировкой по размеру и MIME), создание коллажа 2–6 фото, слайд-шоу с настраиваемым интервалом и список фотографий с GPS-метаданными с открытием координат в картографическом приложении.
- Виджет поддерживает случайную фотографию и размытую миниатюру.
- Содержимое сейфа отображается по приватным альбомам, соответствующим исходным альбомам. Старые файлы в корне сейфа отображаются в группе «Сейф».

## Ограничения, которые нужно учитывать
- Системная корзина Android сама определяет фактический срок окончательного удаления. Выбранный срок в настройках пока является предпочтением приложения и не переписывает политику Android.
- Автоматическое резервное копирование пока не выполняет выгрузку: для него нужно отдельно выбрать и подключить целевое хранилище.
- Выбор языка и формата даты сохраняется, но полная локализация всех строк и единое применение формата дат ещё требуют отдельного этапа.
- Уведомления о воспоминаниях пока не планируются в фоне.
- Карта показывает только фото, в EXIF которых реально сохранены GPS-координаты; встроенная карта без внешнего приложения не добавлена.
- Коллаж сохраняется отдельным JPEG в Pictures/MayskGallery; оригиналы не изменяются.
- «Приватные альбомы» используют существующую защищённую папку сейфа, а не отдельные независимые PIN-коды для каждой папки.
- Миграция скрытых файлов из стороннего/старого хранилища не запускается автоматически без достоверного определения его расположения и проверки старого пароля.

## Проверка
- Выполнена проверка структуры исходников и whitespace diff.
- Полная сборка Android APK в этой среде не выполнялась: Android SDK/Gradle wrapper недоступны. Требуется проверить сборку в Android Studio или GitHub Actions перед публикацией.
