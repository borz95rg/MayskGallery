# Обновление каталога коллажей

## Что изменено
- В карточках макетов вместо абстрактных цветных блоков теперь отображаются реальные фотографии из локальной галереи пользователя.
- Изображения обрезаются по форме и геометрии соответствующего макета.
- Если в галерее нет фотографий, карточка показывает понятное сообщение, а не декоративную заглушку.
- Убрана формулировка «100 авторских шаблонов»; каталог обозначен как готовые композиции.

## Важно
Это обновление исправляет визуальную подачу каталога. Оно **не означает**, что сторонняя библиотека PuzzleLayout уже встроена в редактор. До её подключения нужно проверить совместимость API библиотеки с текущим проектом, обработку Bitmap/Uri, экспорт итогового изображения и локальную сборку. В этой версии сторонняя библиотека не подключалась, чтобы не добавлять непроверенную зависимость и не ломать сборку.

Для проверки откройте проект в Android Studio или GitHub Actions и соберите debug APK. Проверка на физическом устройстве ещё не выполнена.
