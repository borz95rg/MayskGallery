# MayskGallery — обновление редактора коллажей

## Что изменено

- Библиотека содержит 120 выбираемых вариантов компоновки, сгруппированных по категориям: классика, журнальные, мозаика, асимметрия, истории и креатив.
- Перед выбором фотографий пользователь выбирает количество от 2 до 8, затем просматривает схемы подходящей компоновки.
- После выбора макета можно выбрать фотографии, изменить их порядок и заменить отдельные снимки.
- Предпросмотр остаётся доступным до сохранения; подпись можно добавить перед экспортом.
- Сохранение теперь возвращает URI созданного изображения, проверяет размер записанного файла и удаляет неполный файл при ошибке.
- После успешного сохранения приложение автоматически открывает экран результата с самим изображением и подтверждением папки `Pictures/MayskGallery`.
- На экране результата можно вернуться к редактированию или начать новый коллаж.
- Оригинальные фотографии не изменяются.

## Важное о сборке

В архиве нет `.git`, чтобы не перезаписать локальное состояние GitHub Desktop и незавершённое слияние. Распакуйте архив отдельно, затем скопируйте содержимое папки `MayskGallery` поверх существующей рабочей папки репозитория, сохранив её `.git`.

Сборка APK в этой среде не запускалась: Android SDK и Gradle 8.9 здесь не установлены. После копирования запустите workflow Build APK через GitHub Actions или соберите проект в Android Studio.
